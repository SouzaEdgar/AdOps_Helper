# AdOps Helper

AdOps Helper é uma ferramenta web criada para auxiliar na análise e validação de URLs.

O projeto permite visualizar a URL final do redirect, verificar status HTTP e analisar parâmetros presentes nas URLs processadas.

## Funcionalidades
- Processamento de múltiplas URLs
- Visualização do último redirect
- Identificação da URL final
- Verificação de status HTTP
- Extração de parâmetros presentes na URL
- Integração com API própria em Pyhton
- Processamento assíncrono para maior desempenho

## Tecnologias Utilizadas

### Frontend
- HTML
- CSS
- Javascript

  ### Backend/API
  - Python
  - FastAPI
  - HTTPX
